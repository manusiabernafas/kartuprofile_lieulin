## 🎨 Konsep Desain: Neobrutalism
Aplikasi ini dirombak total menggunakan estetika modern **Neobrutalism**:
1. **Bold Black Borders**: Border tegas 2.5px - 3.5px solid black (`#181818`) pada setiap elemen komponen.
2. **Hard Drop Shadows**: Bayangan tegas tanpa blur (`blurRadius: 0`, offset `[4, 4]` s/d `[8, 8]`).
3. **High-Contrast Vibrant Palette**:
   - Cyber Banana Yellow (`#FFE600`)
   - Punchy Neon Pink (`#FF66C4`)
   - Electric Cyan (`#5CE1E6`)
   - Toxic Acid Lime (`#7ED957`)
   - Warm Canvas Cream (`#FFFDF0`)
4. **Micro-Interactions & Tactile Feeling**: Tombol Neobrutalism dengan animasi tekanan fisik nyata (*tactile click*).
5. **Interactive Theme Switcher**: Pengganti warna aksen dinamis langsung dari AppBar.
6. **Vibe Generator**: Fitur easter egg roll quote "Vibe Coder" interaktif.
7. **Quick Copy Action**: Fitur salin NIM, Email, WhatsApp, dan GitHub langsung ke clipboard dengan respon visual SnackBar.
